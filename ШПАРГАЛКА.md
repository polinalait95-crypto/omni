# OmniSpace — шпаргалка

Краткая методичка: запуск, сборка и все ошибки, которые мы прошли, с готовыми
командами. Все команды выполняются **в папке `omnispace`** (там, где `package.json`).

---

## 0. Что где лежит
- **Проект** — папка `omnispace` (`src`, `src-tauri`, `.github`, `package.json`).
- **Данные и файлы** — локально на Маке: `~/Library/Application Support/app.omnispace.desktop/`.
- **Бэкап** — в приложении: Настройки → «Скачать бэкап» (один JSON-файл).

---

## 1. Разовая установка (Mac, один раз)
```bash
xcode-select --install       # инструменты Apple (если предложит — Установить)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh   # Rust, жать Enter
node --version               # Node.js. Если нет — поставить LTS с nodejs.org
```
После установки Rust закрой и открой терминал заново.

---

## 2. Запуск и сборка
```bash
cd путь/к/omnispace      # проще: набрать "cd " и перетащить папку из Finder
npm install              # поставить зависимости (один раз)

npm run tauri dev        # БЫСТРЫЙ просмотр — окно откроется, всё кликается
npm run tauri build      # СБОРКА установщика .dmg (первый раз 10–20 мин — норма)
```
Готовый установщик: `src-tauri/target/release/bundle/dmg/OmniSpace_0.1.0_x64.dmg`
Первый запуск .dmg: правый клик по программе → **Открыть** (приложение не подписано).

---

## 3. Быстрая проверка без долгой сборки
```bash
npx tsc --noEmit         # пусто в ответ = ошибок типов нет, можно собирать
```

## 4. Ошибки, которые мы прошли, и как чинить

### «beforeBuildCommand npm run build failed with exit code 2»
Это упал **фронтенд** (tsc/vite). Сама причина — в строках `error TS...` ВЫШЕ по логу.
Чтобы увидеть коротко: `npx tsc --noEmit`.

### error TS7006: Parameter 'v' implicitly has an 'any' type
Строгий компилятор требует тип. Уже исправлено в `App.tsx`. Если повторится:
```bash
sed -i '' 's/onGoto={(v) => setView(v)}/onGoto={(v: View) => setView(v)}/g' src/App.tsx
```

### error TS1261 (differs only in casing) / TS1192 (no default export) про Carmen
Два файла отличались только регистром (`Carmen.tsx` и `carmen.ts`), Mac их путает.
Исправление (уже сделано):
```bash
mv src/carmen.ts src/carmenBrain.ts
sed -i '' 's|from "./carmen"|from "./carmenBrain"|' src/Carmen.tsx
ls src/[Cc]armen*        # должно быть: Carmen.tsx  carmenBrain.ts  (без carmen.ts)
```

### error TS18003: No inputs were found ... 'src'
Папка `src` пустая/не загрузилась (актуально при заливке через браузер GitHub).
Долить содержимое `src` из архива. На Маке из терминала такого не бывает.

## 5. Сборка через GitHub (Windows + Mac сразу)

Нужна, чтобы получить **Windows-установщик** (локально на Маке его не собрать).

**Залить проект (терминал, Mac):**
```bash
cd путь/к/omnispace
git init
git add -A                        # берёт ВСЮ папку целиком (важно!)
git commit -m "full project"
git branch -M main
git remote add origin https://github.com/ЛОГИН/omnispace.git
git push -u origin main
# если "rejected / fetch first": git push -u origin main --force
```
При `push` откроется браузер для входа — пароль вводить не нужно.

**Запустить сборку:** на сайте репозитория → Releases → Create a new release →
тег `v0.1.0` → Publish. Actions соберёт (~10–15 мин) → готовые файлы в
**Releases → Assets**: `.msi`/`.exe` (Windows) и `.dmg` (Mac).

**Новая сборка = новый тег** (`v0.1.1`, `v0.1.2`, …).

---

## 6. Частые вопросы по GitHub
- **Веб-загрузка теряет папки** (`.github`, `src`) → грузить через терминал (`git add -A`)
  или GitHub Desktop. Перетаскивание в браузере ненадёжно.
- **`.github` не загрузилась → нет сборки** → создать файл через «Add file → New file»
  с именем `.github/workflows/release.yml` (слэши создадут папки).
- **Push просит пароль** → пароль не работает. Вход через браузер, либо
  GitHub Desktop, либо токен: Settings → Developer settings → Tokens → отметить `repo`.

---

## 7. Мелочи, которые не ошибки
- Первая компиляция Rust идёт долго (10–20 мин) — это нормально.
- Предупреждение «Node.js 20 is deprecated» — игнорировать, на сборку не влияет.
- Неподписанное приложение: **Mac** — правый клик → «Открыть»; **Windows** —
  «Подробнее» → «Всё равно запустить».
